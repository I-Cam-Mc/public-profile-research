What the method does

A profile that can be checked, not just believed.

Search discovers leads. The research workflow verifies identity, preserves source context and labels the difference between fact, self-report and bounded inference.

Start from one confirmed profile. Follow public links across search, social profiles, video, code, companies and independent coverage.

V

Verify every material claim

Each statement retains its URL, retrieval time, evidence class and confidence. Contradictions remain attached to the claim.

I

Interpret the public impression

Analyse recurring public themes, communication style and demonstrated interests without turning a curated footprint into a private diagnosis.

“This is how the public material may read, not a claim about the whole person.”
G

Keep the gaps

A platform gate, missing transcript or unresolved identity is a coverage limit. It is never quietly treated as evidence that nothing exists.

What a run can reach depends on the environment.

A local run can use tools and signed-in sessions already configured on your computer. A static copy of this site cannot run those tools, so it exports the same intake and prompt instead.

Public pages, search leads and reader-visible text. A source URL and retrieval status are retained for every target.

Usually available

Public profile fields and repositories can be collected through GitHub’s public API, then analysed with provenance intact.

Built into the local engine

YouTube metadata can use yt-dlp. Other platforms can use Agent Reach or a configured browser session where access is lawful and available.

Environment dependent

Open tools may compare user-supplied images or a collected corpus. This is not a web-scale face search. Private, deleted or inaccessible material stays outside the claim set.
