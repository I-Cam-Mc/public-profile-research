# Platform routes and real boundaries

Read this file only when X, TikTok or LinkedIn is in scope. Recheck current official documentation and live tool health before relying on it.

## X

### Maximum-coverage ladder

1. Official user lookup and official full-archive search when the user approves credentials and current cost.
2. Legitimately authenticated user timeline and Highlights through a supported read-only adapter.
3. Date-bucketed first-party search with every query, interval, cursor and terminal state retained.
4. Public search indexes and lawful archive indexes as candidate-ID discovery only.
5. Exact-ID first-party revalidation before treating archive/index text as current public evidence.

Register base and supplement ledgers together. Edited IDs, replies, quote posts, media and parent context need explicit fields. Do not treat a count-limited timeline command or one archive pilot as a five-year census.

The official archive API can close currently searchable public text when its pagination is exhausted, but it may cost money and still excludes deleted, private, withheld or unsearchable posts. Free routes can materially improve coverage but cannot certify a complete lifetime archive.

## TikTok

### Enumeration and visual review

Use stable current-profile IDs when exposed. The official embed player is a legitimate fallback for playback review. Require a ready event, non-zero duration, time progression and ended state or an exact terminal player error. An HTTP 200 player shell is not a completed video review.

### Speech

Try, in order:

1. creator/platform transcript or voice-to-text exposed by an authorised official surface;
2. legitimately recovered media followed by local audio probing and transcription;
3. continuous caption capture, checked against a stratified audio sample before expansion;
4. authorised normal-page playback and bounded manual transcription;
5. an optional third-party transcript service only after explicit privacy and credential approval.

Retain recovered media until audio extraction, transcription, semantic review and sidecars finish. A video that plays visually but has unresolved speech is not modality-complete. A persistent official-player invalid-video result can become an evidenced barrier only after the approved fallback ladder is exhausted.

## LinkedIn

LinkedIn’s activity feed is virtualised. Visible-node scraping after scrolling can lose posts that were removed from the DOM.

For authorised browser collection:

1. install a read-only `MutationObserver` before scrolling;
2. persist stable activity URNs and canonical links as nodes appear;
3. keep authored posts and reposts separate until after enumeration;
4. continue until a visible end marker or repeated no-growth passes;
5. repeat in a fresh session and compare the ID union;
6. supplement with public indexes, but require first-party LinkedIn revalidation.

A displayed loaded-post count may include reposts and is not necessarily an authored-post denominator. If the interface announces more items than can be reconciled, keep the family partial. There is no assumed free lifetime-post API for arbitrary members.

## General stopping rule

Do not call a source family closed because one tool failed or because one current interface was completely processed. Closure requires adapter exhaustion against the chosen research mode. When a remaining route needs login, payment, eligibility or subject cooperation, stop early enough to ask rather than discovering that dependency after synthesis.
